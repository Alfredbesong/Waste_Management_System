# Project Structure

## Current layout

- `backend/` contains the Django API and admin dashboard
- `lib/` contains the Flutter citizen app
- `test/` contains Flutter widget tests

## Flutter folders

- `lib/app/` app bootstrap and route setup
- `lib/core/` theme, constants, and shared configuration
- `lib/features/` feature-based screens
- `lib/shared/` reusable models and widgets

## Backend folders

- `backend/config/` Django project settings and root URLs
- `backend/apps/users/` registration and authentication
- `backend/apps/reports/` waste report and confirmation logic
